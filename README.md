## Быстрая настройка (How to use)
Установка (install):
```bash
curl -fsSL https://raw.githubusercontent.com/snowybunny/awgwarp/main/script.sh -o /tmp/awgwarp-install.sh && bash /tmp/awgwarp-install.sh
```
После установки, запуск командой (after):
```bash
awgwarp
```
